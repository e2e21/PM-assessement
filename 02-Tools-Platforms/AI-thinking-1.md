# AI有关思考  

## 一. AI的信息源  

### 1.1 上下文对话

- 上下文对话内容，在有限token的上下文窗口里能被记住，超出部分前文被后文取代。
- 但AI有独立记忆功能（与对话上下文不一样），当用户特意要求AI记住事情，就会存储到记忆里。（我问的几个AI,大部分说不知道记忆额度，千问明确说50个记忆项目且可以手动查看管理，豆包不知道额度但是可以手动查看管理）
- 特殊的是手机系统自带ai，我手机的超级小爱记忆功能支持本地存存储（能手动管理），额度受限于设备的咳哟零空间。但是连续对话最长只保留15分钟记忆（数据来源于小米小爱开放平台，小爱同学官方网页）

### 1.2 模型训练的数据源

主要来源是公开合规的海量文本：
	- 公开的教材、教辅资料、习题集
	- 开源的技术文档、官方文档、手册
	- 公开的书籍、论坛讨论、发表文章、科普文章、新闻
	- 各大中英文公开网页

- 条件：问题是对成熟稳定的静态知识时触发。例如高数积分、概率公式、编程语法、书籍介绍
- 特点：有概率出错，计算过程，公式理论都可能出错，尤其是不同步版本教材的特殊约定（我自己遇到过，然后补充了特定条件，AI联网搜索，来源有github、抖音、csdn、还有一些不认识的网站）

### 1.3 实时网页搜索
调用了 **general_search** 之类工具，发起网络搜索。
- 条件：问题需要时效性强的信息。
- 特点：答案会标注来源，可以回溯信息来源；运用网络信息，但是无法辨别来源信息的真假，受网页信息真假影响

## 2. 高质prompt的书写

### 2.1 prompt公式

**角色+背景+任务+约束+格式**

-  角色：告诉AI他是谁（你是一个XXX）
- 背景：告诉AI目的，受众群体（在班上给学生讲课的时候）（需求不能脱离背景）
- 任务：告诉AI要做什么，具体的动作（出一道二元一次方程题目）
- 约束：防止AI偏离目标主题（适合刚接触二元一次方程，乘除法基础薄弱的学生的）
- 格式：明确AI回复的形式（例如生成word文档）

### 2.2 注意事项

-  下达指令时：指令的形容客观具体
-  得到回复不满意：不断通过对话微调
- 对待回复：不盲目相信，AI具有幻觉特性，需要辨证对待。

## 3. AI回复的质量与正确率

### 3.1 首先，AI的答案肯定不都正确
以各AI的基准测试正确率为例

![屏幕截图 2026-11-28 030804.png](https://note-pics-1538697009.cos.ap-guangzhou.myqcloud.com/img/20261128030914883.png)

- 先看最接近官方口径的 AIME 2026：Claude Opus 4.8 达到 100.00%，GPT-5.4 为 99.17%，Gemini 3.1 Pro Preview 为 98.33%，Claude Opus 4.6 为 96.67%。即使是最高的 100%，也只覆盖 **30 道 AIME 题**这一个极窄的任务分布。再看 GPQA Diamond，头部模型集中在 91%–94% 区间；SWE-bench Verified 的生产 API 口径集中在 80% 附近。**没有任何一个前沿模型在所有基准上都达到 100%，也没有任何一个基准能覆盖“所有问题”。**

- 更关键的是：基准上的“正确率”是**特定任务集上的统计估计**，不是“AI 在所有场景下正确回答的概率”。一个在 AIME 上 100% 的模型，完全可能在 GPQA 上错 6 个百分点，在 SWE-bench 上错 20 个百分点——因为这三个基准测的是**不同的能力维度**。

 **数学正确率上 Gemini 更高，但用户盲测把 Claude 投到了第一**。体现用户喜爱度受回答风格、可读性、多轮稳定性、拒绝率等多种因素影响，**正确率只是其中一个维度，而且往往不是决定性维度**。
 
### 3.2 关于答案来源以及可信度

我对数据的查找和筛选几乎都依靠ai，但是有进行AI互查和让AI反复自查验证。
- 第一轮基准测试正确率数据收集时，强调数据要 official 且必须标明可溯源复查的原网站
- 第二轮要求此AI自己溯源复查数据真实性、官方有效性、时效性，生成新的、最确切的结果
- 第三轮用另外三个AI对先前AI的输出结果和来源网站的真实性，官方性进行了核对。
- AI的回复具有“幻觉”、“谄媚”、“滞后”的特点  
	 - 幻觉：在AI无法回答、不知道答案时，喜欢基于概率和大模型数据编造看似合理的假事实
